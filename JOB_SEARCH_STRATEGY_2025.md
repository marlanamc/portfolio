# Job Search Strategy 2025 - Technical Roles

## 📚 What These Roles Actually Are

### QA Tester / QA Analyst - What Do They Do?

**Day-to-Day:**
- **Test software before it goes live** - Click through new features, try to break things, find bugs
- **Write test cases** - Document step-by-step how to test features ("Click login button, enter email, verify error message shows")
- **Report bugs** - When you find something broken, write it up: "When I click submit with empty form, the page crashes instead of showing error"
- **Verify fixes** - After developers fix bugs, test again to make sure it's actually fixed
- **Manual testing** - Actually using the software like a user would
- **Sometimes automated testing** - Writing scripts to test things automatically (but entry-level is usually manual)

**Real Example:**
- Company releases new login feature
- QA tester tries: logging in with wrong password, empty fields, special characters, etc.
- Finds bug: "Login button doesn't work on mobile"
- Reports it to developers
- Tests again after fix

**Why It's Good for You:**
- You've already done this! You tested your LMS, your Firebase app, your games
- You found bugs, fixed them, tested again
- It's like being a careful user who gets paid to find problems

**Salary Range (Boston):**
- Entry-level: $50k-70k
- With experience: $70k-90k

---

### Technical Implementation Specialist - What Do They Do?

**Day-to-Day:**
- **Set up software for new customers** - When a company buys software, you configure it for them
- **Onboard users** - Train them how to use it, create accounts, set permissions
- **Configure integrations** - Connect the software to their other tools (like connecting Salesforce to their email system)
- **Troubleshoot setup issues** - "Why isn't the API connecting?" "Why can't users log in?"
- **Write documentation** - Create guides for customers
- **Work with customers** - Lots of email/phone calls helping them get set up

**Real Example (EdTech):**
- School district buys a new LMS (like Canvas or Blackboard)
- Implementation specialist:
  1. Sets up the system (creates school accounts, imports student data)
  2. Configures settings (grading scales, course templates)
  3. Trains teachers how to use it
  4. Connects it to their student information system
  5. Troubleshoots: "Why can't teachers see their classes?" "How do I upload grades?"

**Why It's Perfect for You:**
- You literally did this! You built an LMS, deployed it, onboarded 50+ students, trained them
- You configured Firebase Auth, set up access controls
- You wrote user guides
- This is exactly what you've been doing with your projects

**Salary Range (Boston):**
- Entry-level: $55k-75k
- With experience: $75k-100k

### Technical Support Specialist - What Do They Do?

**Day-to-Day:**
- **Answer customer questions** - "How do I reset my password?" "Why isn't this feature working?"
- **Troubleshoot problems** - Customer says "My dashboard is broken" - you figure out why
- **Escalate complex issues** - If it's a real bug, send to engineering team
- **Write knowledge base articles** - Document common problems and solutions
- **Help customers via email/chat/phone** - Customer service but technical

**Real Example:**
- Customer emails: "I can't log into the platform"
- You: Check their account, reset password, test login, walk them through it
- Or: "The export feature isn't working"
- You: Reproduce the issue, check logs, maybe it's a bug → escalate to engineering

**Why It's PERFECT for You:**
- **8 years as a server = expert customer service skills** - You know how to handle difficult customers, stay calm under pressure, communicate clearly
- You've done user support for your own apps
- You troubleshoot technical issues all the time
- You write documentation
- You understand both technical and user perspectives
- **Server experience = you're great at:**
  - Multi-tasking (handling multiple tables = handling multiple support tickets)
  - Working under pressure (rush hour = support ticket rush)
  - De-escalating situations (angry customer = frustrated user)
  - Clear communication (explaining menu = explaining technical solutions)
  - Patience and empathy (dealing with picky customers = helping confused users)

**Salary Range (Boston):**
- Entry-level: $45k-65k
- With experience: $65k-85k
