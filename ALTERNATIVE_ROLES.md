# ALTERNATIVE ROLES: Where You Can Code Without Being a SWE

**The Strategy:** Get your foot in the door with roles that aren't as competitive, but still let you code and grow technical skills. Many companies appreciate developers in non-dev roles who can actually build tools.

---

## 🎯 CATEGORY 1: Technical Product/Program Management

### **Product Manager (Technical)**
**Why it works:** Your teaching + building background gives you product sense
**What you'd do:** Work with developers to build features, write specs, maybe build prototypes
**Can you code?** YES - you'll build prototypes, small tools, internal dashboards
**Salary:** $100-150K+
**How to get in:** Emphasize product thinking + technical execution

**Target Companies:**
- Small startups (under 50 people) need PMs who can also code
- EdTech companies - they LOVE people who understand education + tech
- Look for: "Product Manager", "Technical Product Manager", "Associate Product Manager"

**Cover Letter Angle:** "I've built products that solve real problems my students faced. I can write user stories AND build prototypes to validate them."

---

### **Technical Program Manager**
**Why it works:** Operations background + HKS project management + technical skills
**What you'd do:** Coordinate technical projects, track deliverables, maybe automate reporting
**Can you code?** YES - automation scripts, internal tools, dashboards
**Salary:** $90-130K
**How to get in:** Emphasize project coordination + technical chops

**Target Companies:**
- Harvard, MIT (they hire TPMs for research initiatives)
- Government contractors (MITRE, Draper Labs)
- Larger tech companies (Wayfair, HubSpot)

**Cover Letter Angle:** "Managed research projects at Harvard, built automation tools at Homesite, coordinated restaurant operations. I understand both the technical and operational sides."

**Can you code?** YES - custom integrations, API work, automation
**Salary:** $70-100K

**Target Companies:**
- SaaS companies (HubSpot, Salesforce, any B2B software)
- EdTech companies (they need people to help schools set up platforms)
- Healthcare tech (setting up EHR integrations)

**Cover Letter Angle:** "Teaching adults how to use new technology taught me how to explain complex systems. Plus I can write the integration scripts myself."
